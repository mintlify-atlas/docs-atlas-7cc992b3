The **Oficina Mecânica API** is a RESTful service built with FastAPI, SQLAlchemy, and Alembic. It provides complete workshop management: register clients and their vehicles, assign mechanics, open and track service orders, record technical diagnostics, manage parts and service catalogs, and process payments — all through a clean HTTP API backed by PostgreSQL or SQLite.

## What the API covers

The API is organized around the core entities of a mechanical workshop:

<CardGroup cols={3}>
  <Card title="Clients" icon="users" href="/api/clientes">
    Register vehicle owners with contact details and manage their profiles.
  </Card>
  <Card title="Vehicles" icon="car" href="/api/veiculos">
    Track vehicles by plate, brand, model, year, and fuel type — linked to their owner.
  </Card>
  <Card title="Mechanics" icon="wrench" href="/api/mecanicos">
    Manage mechanics and their specialties (general mechanics, electronics, brakes, etc.).
  </Card>
  <Card title="Service Orders" icon="clipboard-list" href="/api/ordens-servico">
    Central workflow entity: open, progress, complete, or cancel a workshop job.
  </Card>
  <Card title="Diagnostics" icon="stethoscope" href="/api/diagnosticos">
    Record the initial technical inspection for each service order.
  </Card>
  <Card title="Payments" icon="credit-card" href="/api/pagamentos">
    Log payments per service order via PIX, credit, debit, or cash.
  </Card>
</CardGroup>

## Get up and running

<Steps>
  <Step title="Clone the repository and install dependencies">
    Set up a Python virtual environment and install all required packages from `requirements.txt`.
  </Step>
  <Step title="Configure your database">
    Set the `DATABASE_URL` environment variable to point at PostgreSQL or use the default SQLite database.
  </Step>
  <Step title="Run database migrations">
    Apply the Alembic migration history to create all tables in your database.
  </Step>
  <Step title="Start the API server">
    Launch the FastAPI app with Uvicorn and explore the interactive docs at `/docs`.
  </Step>
</Steps>

<Note>
  Head to the [Quickstart](/quickstart) for the full step-by-step setup with commands.
</Note>

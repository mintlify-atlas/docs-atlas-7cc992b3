The `app/seed.py` script populates the database with a rich set of realistic sample data so you can explore the full API immediately after setup — without having to create records by hand. All data is based on a Brazilian mechanical workshop context, with real Brazilian names, license plates, auto part names, and service descriptions.

## Run the seed script

Make sure you have already applied all migrations before seeding. Then run the script as a Python module from the project root:

```bash
python -m app.seed
```

The script is **idempotent**. On startup it queries the `cliente` table to check whether data already exists. If at least one client record is found, it prints the following message and exits immediately without inserting any duplicates:

```text
Bando de dados já alimentado.
```

<Note>
  The idempotency message `"Bando de dados já alimentado."` is a typo in the source (`Bando` instead of `Banco`) but is reproduced here exactly as it appears in `app/seed.py`.
</Note>

On a fresh database the script prints progress markers and finishes with:

```text
Semente iniciada
Semente virou arvore com sucesso!
```

## What gets created

The seed script inserts records in dependency order — clients and mechanics before vehicles, vehicles before service orders, and so on — to satisfy all foreign key constraints.

| Entity | Count | Notable details |
|---|---|---|
| `Cliente` | 10 | Real Brazilian names with unique email addresses and phone numbers |
| `Veiculo` | 20 | Distributed across all 10 clients; various brands, models, and model years (2018–2023) |
| `Mecanico` | 10 | Specialists covering `MECANICA_GERAL`, `INJECAO_ELETRONICA`, `AR_CONDICIONADO`, `MOTOR_RETIFICA`, `SUSPENSAO_FREIOS`, and `CAMBIO_AUTOMATICO` |
| `Peca` | 30 | Real auto parts with unit prices — oil filters, brake pads, shock absorbers, timing belts, sensors, and more |
| `Servico` | 30 | Real workshop services with labor prices — oil changes, alignment, brake service, electronic diagnostics, preventive reviews, and more |
| `OrdemServico` | 15 | Mix of statuses: 8 `CONCLUIDA`, 3 `EM_ANDAMENTO`, 3 `AGENDADA`, 1 `CANCELADA` |
| `ItemServico` | 20 | Labor line items linked to service orders, each referencing a `Servico` |
| `ItemPeca` | 20 | Parts line items linked to service orders, each referencing a `Peca` with quantity and unit price |
| `Diagnostico` | 10 | Technical inspections for the first 10 service orders, including mileage, body damage notes, and fuel level |
| `Pagamento` | 10 | Payments for completed and in-progress orders using PIX, credit card, debit card, and cash |

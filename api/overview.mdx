The Oficina Mecânica REST API provides a complete set of CRUD endpoints for managing the day-to-day operations of a mechanical workshop. Built with FastAPI and SQLAlchemy, the API covers core resources such as clients, mechanics, vehicles, services, parts, service orders, diagnostics, and payments — all served over JSON with consistent pagination envelopes and structured error responses.

## Base URL

All endpoints are relative to the development base URL:

```text
http://localhost:8000
```

There is no path prefix — resource routes are mounted directly at the root (e.g. `http://localhost:8000/clientes/`).

## Interactive Documentation

FastAPI auto-generates two interactive documentation UIs from the OpenAPI schema:

| Interface | URL |
|-----------|-----|
| Swagger UI | [`http://localhost:8000/docs`](http://localhost:8000/docs) |
| ReDoc | [`http://localhost:8000/redoc`](http://localhost:8000/redoc) |

Both interfaces let you inspect request/response schemas and execute live requests without any additional tooling.

## Content Type

All requests and responses use `application/json`. Include the `Content-Type: application/json` header on every request that sends a body.

## HTTP Status Codes

| Code | Meaning | When it is returned |
|------|---------|---------------------|
| `200` | OK | Successful `GET` or `DELETE` |
| `201` | Created | Successful `POST` or `PATCH` |
| `404` | Not Found | The requested resource ID does not exist |
| `409` | Conflict | Duplicate unique field (e.g. email, license plate) or a foreign-key constraint violation |
| `422` | Unprocessable Entity | Business rule violation or Pydantic validation error |
| `500` | Internal Server Error | Unhandled server-side error |

## Error Response Format

When the API returns a `4xx` or `5xx` status code, the response body follows this structure:

```json
{
  "error": "ExceptionClassName",
  "detail": "Human-readable message describing what went wrong"
}
```

**Exception class names used by the API:**

| Class | Status | Typical cause |
|-------|--------|---------------|
| `RecursoNaoEncontradoException` | 404 | Resource ID does not exist |
| `CampoDuplicadoException` | 409 | Unique constraint violated (email, license plate) |
| `ViolacaoChaveEstrangeiraException` | 409 | FK violation — delete blocked by dependent records, or referenced entity missing |
| `RegraDeNegocioException` | 422 | Business rule violated |
| `AppError` | 500 | Unhandled internal error |

The **Clients** resource (`/clientes`) represents the vehicle owners who bring their cars to the workshop. Each client record stores a name, phone number, and a unique email address. Clients are the root entity of the data model — vehicles are owned by clients, and service orders are opened against a client's vehicle. Attempting to delete a client who still has vehicles or open service orders will return a `409 Conflict`.

---

## POST /clientes/

Register a new client in the workshop system.

### Request body

<ParamField body="nome" type="string" required>
  Full name of the client. Must be between 3 and 150 characters.
</ParamField>

<ParamField body="telefone" type="string" required>
  Phone number of the client. Maximum 11 characters (digits only, no formatting).
</ParamField>

<ParamField body="email" type="string" required>
  Email address of the client. Must be between 3 and 120 characters and **unique** across all clients.
</ParamField>

### Response `201 Created`

Returns the newly created client as a `ClientePublic` object.

<ResponseField name="id" type="integer">
  Auto-generated primary key.
</ResponseField>

<ResponseField name="nome" type="string">
  Client name.
</ResponseField>

<ResponseField name="telefone" type="string">
  Client phone number.
</ResponseField>

<ResponseField name="email" type="string">
  Client email address.
</ResponseField>

<ResponseField name="created_at" type="string (datetime)">
  ISO 8601 UTC timestamp of when the record was created.
</ResponseField>

<ResponseField name="updated_at" type="string (datetime)">
  ISO 8601 UTC timestamp of the last update.
</ResponseField>

### Example

```bash
curl -X POST http://localhost:8000/clientes/ \
  -H 'Content-Type: application/json' \
  -d '{"nome": "Carlos Eduardo Silva", "telefone": "85999911101", "email": "carlos.silva@email.com"}'
```

```json
{
  "id": 1,
  "nome": "Carlos Eduardo Silva",
  "telefone": "85999911101",
  "email": "carlos.silva@email.com",
  "created_at": "2024-06-10T14:22:05.123456Z",
  "updated_at": "2024-06-10T14:22:05.123456Z"
}
```

### Errors

| Status | Class | Condition |
|--------|-------|-----------|
| `409` | `CampoDuplicadoException` | A client with the given `email` already exists. |

## GET /clientes/

List all clients with optional pagination and filtering by name or email.

### Query parameters

<ParamField query="pagina" type="integer" default="1">
  Page number to retrieve. Must be ≥ 1.
</ParamField>

<ParamField query="tamanho_pagina" type="integer" default="10">
  Number of records per page. Must be between 1 and 100.
</ParamField>

<ParamField query="nome" type="string">
  Optional. Case-insensitive partial match against the client's `nome` field.
</ParamField>

<ParamField query="email" type="string">
  Optional. Case-insensitive partial match against the client's `email` field.
</ParamField>

### Response `200 OK`

Returns a `ClientePage` envelope.

<ResponseField name="dados" type="array">
  List of `ClientePublic` objects matching the query.
</ResponseField>

<ResponseField name="paginacao" type="object">
  Pagination metadata.

  <Expandable title="paginacao fields">
    <ResponseField name="total_registros" type="integer">
      Total number of clients matching the current filter.
    </ResponseField>
    <ResponseField name="total_paginas" type="integer">
      Total number of pages given the current `tamanho_pagina`.
    </ResponseField>
    <ResponseField name="pagina_atual" type="integer">
      The page number returned in this response.
    </ResponseField>
    <ResponseField name="tamanho_pagina" type="integer">
      The page size used for this response.
    </ResponseField>
  </Expandable>
</ResponseField>

### Example

```bash
curl "http://localhost:8000/clientes/?pagina=1&tamanho_pagina=5&nome=carlos"
```

```json
{
  "dados": [
    {
      "id": 1,
      "nome": "Carlos Eduardo Silva",
      "telefone": "85999911101",
      "email": "carlos.silva@email.com",
      "created_at": "2024-06-10T14:22:05.123456Z",
      "updated_at": "2024-06-10T14:22:05.123456Z"
    }
  ],
  "paginacao": {
    "total_registros": 1,
    "total_paginas": 1,
    "pagina_atual": 1,
    "tamanho_pagina": 5
  }
}
```

## GET /clientes/\{cliente_id\}

Fetch a single client by their numeric ID.

### Path parameters

<ParamField path="cliente_id" type="integer" required>
  The unique integer ID of the client to retrieve.
</ParamField>

### Response `200 OK`

Returns a `ClientePublic` object.

```bash
curl http://localhost:8000/clientes/1
```

```json
{
  "id": 1,
  "nome": "Carlos Eduardo Silva",
  "telefone": "85999911101",
  "email": "carlos.silva@email.com",
  "created_at": "2024-06-10T14:22:05.123456Z",
  "updated_at": "2024-06-10T14:22:05.123456Z"
}
```

### Errors

| Status | Class | Condition |
|--------|-------|-----------|
| `404` | `RecursoNaoEncontradoException` | No client with the given `cliente_id` exists. |

## PATCH /clientes/\{cliente_id\}

Partially update one or more fields of an existing client. Only the fields included in the request body are modified; omitted fields remain unchanged.

### Path parameters

<ParamField path="cliente_id" type="integer" required>
  The unique integer ID of the client to update.
</ParamField>

### Request body (`ClienteUpdate` — all fields optional)

<ParamField body="nome" type="string">
  New client name. Must be between 3 and 150 characters if provided.
</ParamField>

<ParamField body="telefone" type="string">
  New phone number. Maximum 11 characters if provided.
</ParamField>

<ParamField body="email" type="string">
  New email address. Must be between 3 and 120 characters and unique if provided.
</ParamField>

### Response `201 Created`

Returns the updated `ClientePublic` object.

```bash
curl -X PATCH http://localhost:8000/clientes/1 \
  -H 'Content-Type: application/json' \
  -d '{"telefone": "85988822200"}'
```

```json
{
  "id": 1,
  "nome": "Carlos Eduardo Silva",
  "telefone": "85988822200",
  "email": "carlos.silva@email.com",
  "created_at": "2024-06-10T14:22:05.123456Z",
  "updated_at": "2024-06-10T15:00:00.000000Z"
}
```

### Errors

| Status | Class | Condition |
|--------|-------|-----------|
| `404` | `RecursoNaoEncontradoException` | No client with the given `cliente_id` exists. |
| `409` | `CampoDuplicadoException` | The new `email` is already registered to another client. |

## DELETE /clientes/\{cliente_id\}

Permanently remove a client from the system. This operation is blocked if the client has any associated vehicles or service orders.

### Path parameters

<ParamField path="cliente_id" type="integer" required>
  The unique integer ID of the client to delete.
</ParamField>

### Response `200 OK`

```bash
curl -X DELETE http://localhost:8000/clientes/1
```

```json
{
  "message": "Cliente removido com sucesso"
}
```

### Errors

| Status | Class | Condition |
|--------|-------|-----------|
| `404` | `RecursoNaoEncontradoException` | No client with the given `cliente_id` exists. |
| `409` | `ViolacaoChaveEstrangeiraException` | Client has associated vehicles or service orders and cannot be removed. |

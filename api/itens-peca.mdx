`ItemPeca` links a `Peca` from the parts catalog to a `OrdemServico`. Each record tracks how many units of a part were consumed (`quantidade`), the unit price that was frozen at item creation (`preco_unitario`), and whether the client approved the use of that part. A single service order can contain multiple `ItemPeca` records — one for each distinct part used during the repair or maintenance visit.

This resource has no standalone route file. Part item operations are performed through the `/ordens-servico` endpoint family.

## Schema

### Request fields (create / update)

<ParamField body="quantidade" type="integer">
  Number of units of the part consumed. Must be **greater than 0**. Defaults to `1`.
</ParamField>

<ParamField body="preco_unitario" type="float">
  Per-unit price at item creation, in Brazilian Reais (BRL). Must be **≥ 0**. Defaults to `0.0`. This value is **frozen at creation** — it is copied from `Peca.preco` when the item is added and is unaffected by future catalog price changes.
</ParamField>

<ParamField body="aprovado" type="boolean">
  Whether the client approved the use of this part. Defaults to `true`. Items with `aprovado = false` are excluded from `OrdemServico.valor_total` and from payment eligibility.
</ParamField>

<ParamField body="peca_id" type="integer" required>
  Foreign key referencing the `Peca` catalog entry this line item is based on.
</ParamField>

<ParamField body="ordem_servico_id" type="integer" required>
  Foreign key referencing the `OrdemServico` this line item belongs to.
</ParamField>

### Response fields

<ResponseField name="id" type="integer">
  Auto-generated primary key. Assigned by the database on creation.
</ResponseField>

<ResponseField name="quantidade" type="integer">
  Number of units of the part consumed.
</ResponseField>

<ResponseField name="preco_unitario" type="float">
  Per-unit price frozen at item creation, in BRL.
</ResponseField>

<ResponseField name="aprovado" type="boolean">
  Whether the client approved this line item.
</ResponseField>

<ResponseField name="peca_id" type="integer">
  Foreign key referencing the `Peca` catalog entry.
</ResponseField>

<ResponseField name="ordem_servico_id" type="integer">
  Foreign key referencing the parent `OrdemServico`.
</ResponseField>

<ResponseField name="created_at" type="datetime">
  ISO 8601 UTC timestamp of when the record was created.
</ResponseField>

<ResponseField name="updated_at" type="datetime">
  ISO 8601 UTC timestamp of the last update.
</ResponseField>

### Update fields (all optional)

A `PATCH` request may include any subset of the following fields. The order must not be in `concluida` or `cancelada` status.

<ParamField body="quantidade" type="integer">
  Updated unit count. Must be greater than 0.
</ParamField>

<ParamField body="preco_unitario" type="float">
  Updated unit price. Must be ≥ 0.
</ParamField>

<ParamField body="aprovado" type="boolean">
  Updated client approval flag.
</ParamField>

<ParamField body="peca_id" type="integer">
  Reassigns the item to a different part in the catalog.
</ParamField>

<ParamField body="ordem_servico_id" type="integer">
  Reassigns the item to a different service order.
</ParamField>

## Error Codes

| Status | Exception                          | When it occurs                                                                |
|--------|------------------------------------|-------------------------------------------------------------------------------|
| 404    | `RecursoNaoEncontradoException`    | The item ID, `peca_id`, or `ordem_servico_id` does not exist.                 |
| 409    | `ViolacaoChaveEstrangeiraException` | The supplied `peca_id` or `ordem_servico_id` references a non-existent record. |
| 422    | `RegraDeNegocioException`          | Attempt to add or modify an item on a `concluida` or `cancelada` order.       |

## Price Invariance

At the moment an `ItemPeca` is created, `Peca.preco` is copied into `preco_unitario`. This snapshot is immutable: any subsequent update to the part's price in the catalog does not affect existing line items. This guarantees that invoices accurately reflect the prices agreed upon when the budget was presented to the client.

```text
parts_contribution = quantidade × preco_unitario   (only when aprovado = true)
```

## Billing Contribution

Only items with `aprovado = true` are included in the `OrdemServico.valor_total` calculation. The contribution formula for each approved `ItemPeca` is:

```text
item_total = quantidade × preco_unitario
```

For example, an item with `quantidade = 4` and `preco_unitario = 48.00` contributes **R$ 192.00** to the order total. An item with `aprovado = false` contributes **R$ 0.00** regardless of quantity or unit price.

## Locked Orders

Service orders with a status of `concluida` (completed) or `cancelada` (cancelled) are immutable. Attempting to add, modify, or remove an `ItemPeca` on a locked order raises a `RegraDeNegocioException`:

```json
{
  "status_code": 422,
  "detail": "Regra de negócio violada"
}
```

## Examples

### Create request

The following body adds four litres of synthetic 5W30 motor oil (part ID 1, R$ 48.00/unit) to service order 1, approved by the client:

```json
{
  "quantidade": 4,
  "preco_unitario": 48.0,
  "aprovado": true,
  "peca_id": 1,
  "ordem_servico_id": 1
}
```

### Create response

```json
{
  "id": 1,
  "quantidade": 4,
  "preco_unitario": 48.0,
  "aprovado": true,
  "peca_id": 1,
  "ordem_servico_id": 1,
  "created_at": "2025-01-01T10:00:00Z",
  "updated_at": "2025-01-01T10:00:00Z"
}
```

### Declined item example

The following record is from order #4 (brake service). The front brake disc pair was included in the budget but declined by the client — the item is stored with `aprovado = false` and contributes nothing to the order total:

```json
{
  "id": 7,
  "quantidade": 1,
  "preco_unitario": 320.0,
  "aprovado": false,
  "peca_id": 10,
  "ordem_servico_id": 4,
  "created_at": "2025-01-10T09:00:00Z",
  "updated_at": "2025-01-10T09:00:00Z"
}
```

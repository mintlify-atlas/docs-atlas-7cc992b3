`ItemServico` is the associative entity that links a `Servico` from the workshop's service catalog to a `OrdemServico`. Each record captures how many hours were worked (`tempo_hora`), the hourly rate that was frozen at item creation (`valor_hora`), and whether the client approved this specific line item. A single service order can have multiple `ItemServico` records — one for each distinct service performed during the visit.

This resource has no standalone route file. Service item operations are performed through the `/ordens-servico` endpoint family.

## Schema

### Request fields (create / update)

<ParamField body="tempo_hora" type="integer">
  Number of hours worked on this service. Must be **greater than 0**. Defaults to `1`.
</ParamField>

<ParamField body="valor_hora" type="float">
  Hourly rate applied for this service, in Brazilian Reais (BRL). Must be **≥ 0**. Defaults to `0.0`. This value is **frozen at creation** — it is copied from `Servico.preco` when the item is added and is unaffected by future catalog price changes.
</ParamField>

<ParamField body="aprovado" type="boolean">
  Whether the client approved this service line item. Defaults to `true`. Items with `aprovado = false` are excluded from `OrdemServico.valor_total` and from payment eligibility.
</ParamField>

<ParamField body="servico_id" type="integer" required>
  Foreign key referencing the `Servico` catalog entry this line item is based on.
</ParamField>

<ParamField body="ordem_servico_id" type="integer" required>
  Foreign key referencing the `OrdemServico` this line item belongs to.
</ParamField>

### Response fields

<ResponseField name="id" type="integer">
  Auto-generated primary key. Assigned by the database on creation.
</ResponseField>

<ResponseField name="tempo_hora" type="integer">
  Number of hours worked on this service.
</ResponseField>

<ResponseField name="valor_hora" type="float">
  Hourly rate frozen at item creation, in BRL.
</ResponseField>

<ResponseField name="aprovado" type="boolean">
  Whether the client approved this line item.
</ResponseField>

<ResponseField name="servico_id" type="integer">
  Foreign key referencing the `Servico` catalog entry.
</ResponseField>

<ResponseField name="ordem_servico_id" type="integer">
  Foreign key referencing the parent `OrdemServico`.
</ResponseField>

<ResponseField name="created_at" type="datetime">
  ISO 8601 UTC timestamp of when the record was created.
</ResponseField>

<ResponseField name="updated_at" type="datetime">
  ISO 8601 UTC timestamp of the last update.
</ResponseField>

### Update fields (all optional)

A `PATCH` request may include any subset of the following fields. The order must not be in `concluida` or `cancelada` status.

<ParamField body="tempo_hora" type="integer">
  Updated hours worked. Must be greater than 0.
</ParamField>

<ParamField body="valor_hora" type="float">
  Updated hourly rate. Must be ≥ 0.
</ParamField>

<ParamField body="aprovado" type="boolean">
  Updated client approval flag.
</ParamField>

<ParamField body="servico_id" type="integer">
  Reassigns the item to a different service in the catalog.
</ParamField>

<ParamField body="ordem_servico_id" type="integer">
  Reassigns the item to a different service order.
</ParamField>

## Error Codes

| Status | Exception                          | When it occurs                                                               |
|--------|------------------------------------|------------------------------------------------------------------------------|
| 404    | `RecursoNaoEncontradoException`    | The item ID, `servico_id`, or `ordem_servico_id` does not exist.             |
| 409    | `ViolacaoChaveEstrangeiraException` | The supplied `servico_id` or `ordem_servico_id` references a non-existent record. |
| 422    | `RegraDeNegocioException`          | Attempt to add or modify an item on a `concluida` or `cancelada` order.      |

## Price Invariance

When an `ItemServico` is created, the system copies the current `Servico.preco` value into `valor_hora`. From that point on `valor_hora` is immutable with respect to catalog changes — if the workshop raises or lowers the service price later, existing `ItemServico` records retain the rate that was in effect when the item was first added. This ensures consistent invoicing across the full lifespan of a service order.

```text
labour_contribution = tempo_hora × valor_hora   (only when aprovado = true)
```

## Approval Workflow

Client approval is tracked at the individual line-item level via the `aprovado` boolean. This supports partial-approval scenarios where a client agrees to some services but declines others during the budgeting phase.

<Note>
  Only items with `aprovado = true` are counted in `OrdemServico.valor_total`. A declined item (`aprovado = false`) remains on the order as a record of what was proposed and refused, but contributes R$ 0.00 to the billable total regardless of hours or rate.
</Note>

## Locked Orders

Service orders with a status of `concluida` (completed) or `cancelada` (cancelled) are immutable. Attempting to add, modify, or remove an `ItemServico` on a locked order raises a `RegraDeNegocioException`:

```json
{
  "status_code": 422,
  "detail": "Regra de negócio violada"
}
```

## Examples

### Create request

The following body adds a service item for an oil change (service ID 1, R$ 85.00/h) to service order 1. The item has not yet been approved by the client:

```json
{
  "tempo_hora": 1,
  "valor_hora": 85.0,
  "aprovado": false,
  "servico_id": 1,
  "ordem_servico_id": 1
}
```

### Create response

```json
{
  "id": 1,
  "tempo_hora": 1,
  "valor_hora": 85.0,
  "aprovado": false,
  "servico_id": 1,
  "ordem_servico_id": 1,
  "created_at": "2025-01-01T10:00:00Z",
  "updated_at": "2025-01-01T10:00:00Z"
}
```

### Approved item example

The following record is from order #3 (electronic injection fault). The ultrasonic injector cleaning service was approved by the client — service catalog entry #9, priced at R$ 210.00:

```json
{
  "id": 4,
  "tempo_hora": 1,
  "valor_hora": 210.0,
  "aprovado": true,
  "servico_id": 9,
  "ordem_servico_id": 3,
  "created_at": "2025-01-05T09:00:00Z",
  "updated_at": "2025-01-05T09:00:00Z"
}
```
